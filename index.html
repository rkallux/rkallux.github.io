Text description of this diagram

The chip has five main parts. At the top are a RISC-V core, which runs the program, and a 4x4 systolic array, a grid of 16 math units that does matrix multiplication for machine learning. Both connect down to a memory crossbar, a switch that lets them share memory. The crossbar connects to SRAM, the fast on-chip memory. An SPI interface also connects to the crossbar and links the chip to a host computer outside the chip, which is how we load programs and read results when testing the real silicon.
